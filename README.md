# 國小數學能力測驗題庫

18題（含3題「補充題目｜考試範圍待確認」），全部正常計分。純靜態HTML/CSS/JavaScript，不需後端。

## GitHub Pages
將本資料夾的內容上傳至儲存庫根目錄，保留assets結構及.nojekyll。Settings → Pages → Deploy from a branch → main → /(root) → Save。請勿再包一層資料夾，勿上傳上層原始教材或核讀報告。

本機可雙擊index.html。發布後每位同學的紀錄只存在自己的瀏覽器localStorage；更換裝置或網址不自動同步，可用匯出／匯入備份搬移。本機舊紀錄也可用此方式移至公開網址。

原題影像保留年份、題號、選項、符號與原卷水印；未附原始PDF、Word、老師補充照片、學生資料或金鑰。正式題庫僅111～115年，保留原卷頁碼，不建立不存在的本機PDF連結。110年影像為舊版保留資源，未列入正式題庫，可不重新上傳。
